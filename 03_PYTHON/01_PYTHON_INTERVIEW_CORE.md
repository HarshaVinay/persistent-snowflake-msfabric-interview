# Python Interview Core

## P0
Types, mutability, list/tuple/set/dict, functions, lambda, comprehensions, iterators/generators, OOP, exceptions, files, JSON, regex, modules/packages, logging.

## Common questions
- List vs tuple vs set.
- Mutable vs immutable; name objects that are mutable.
- `==` vs `is`.
- Shallow vs deep copy.
- List comprehension.
- `*args` vs `**kwargs`.
- Iterator vs generator.
- `yield`.
- Exception hierarchy and `try/except/else/finally`.
- Context manager and `with`.
- Class/object; encapsulation/inheritance/polymorphism/abstraction.
- Module vs package.
- JSON load/dump.
- Logging levels.

## Data-engineering coding patterns
- Count frequencies with `Counter`.
- Remove duplicates while preserving order.
- Find second largest without sorting twice.
- Group records by key.
- Parse JSON and flatten selected fields.
- Read file, validate rows, write clean output.

## Interview rule
Explain the trade-off, then code the simplest correct solution. Never claim production use of a library you only studied.
