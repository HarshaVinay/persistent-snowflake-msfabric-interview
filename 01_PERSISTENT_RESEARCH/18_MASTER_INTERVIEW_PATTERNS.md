# Persistent Interview Master Patterns

## Evidence-backed pattern
Current public Persistent Data Engineer material emphasizes hands-on coding, SQL/window functions, PySpark transformations, Snowflake/cloud data warehousing, ADF/cloud pipelines, Medallion architecture, performance optimization, data privacy, and project/scenario discussion. Recent candidate reports are not guarantees and vary by role and experience.

## Strong recurring question families

### SQL
- Second/third highest salary.
- Employee salary greater than manager.
- Window functions.
- Duplicate removal/latest-row logic.
- Aggregations and joins.

### Python/PySpark
- Build a DataFrame.
- Clean nulls and duplicates.
- Parse nested JSON.
- RDD operations.
- Window functions.
- Narrow vs wide transformations.
- Data skew and optimization.

### Snowflake
- Zero-copy cloning.
- Stages/file formats/COPY.
- MERGE and QUALIFY.
- Streams/CDC.
- Query optimization and warehouse sizing.

### Architecture
- ETL/ELT.
- Dimensional modeling.
- SCD Type 2.
- Bronze/Silver/Gold.
- Incremental loading.
- Failure recovery.
- PII/security.

## Fresher rule
Be strongest on training material + resume/project. Do not fake production ownership. Say "I studied" for technology learned only in training and "I implemented" only where the project supports it.

## Answer pattern
**Definition → why → example → implementation → trade-off → failure mode → project connection.**
