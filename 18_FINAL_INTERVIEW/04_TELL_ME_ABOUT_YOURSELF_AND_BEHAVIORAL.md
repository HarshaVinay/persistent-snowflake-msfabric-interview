# Tell Me About Yourself + Behavioral

## 60-second structure
1. Current status: Revature-trained fresher targeting Data Engineering.
2. Core stack: Python, SQL, Spark/PySpark, Snowflake, Fabric/Azure and data engineering fundamentals.
3. Projects: Disaster Affected Region Tracker and Cricket Analytics Data Engineering.
4. Strength: turning raw data into clean, analytical datasets and explaining the pipeline end to end.
5. Motivation: build reliable cloud data platforms and grow in a client delivery environment.

## Questions
- Tell me about yourself.
- Why Data Engineering?
- Why Persistent?
- Why Snowflake/Fabric?
- Explain your strongest project.
- What was your hardest technical problem?
- What did you do when you did not know something?
- How do you handle feedback?
- How do you debug a production issue?
- Why should we select you?

## Truth rule
Separate: **implemented**, **practiced**, and **studied**. Never inflate project ownership or production experience.

## Project answer format
Problem → data → architecture → your contribution → transformations → quality → result → challenge → improvement.
