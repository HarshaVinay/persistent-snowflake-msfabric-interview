# Master Notes Standard

This repository now uses **master-note files** like the earlier Spark and Snowflake notes the user found useful.

Each curriculum domain gets a structured, interview-oriented note that combines:

1. What the training topic means.
2. Simple mental model.
3. Syntax/code where applicable.
4. Important differences/comparisons.
5. Common mistakes.
6. Interview-ready answer.
7. Practical/scenario questions.
8. Coding questions.
9. Project connection.
10. Revision checklist.

## Evidence discipline
- A/B = reported Persistent interview evidence.
- C = strong prediction from curriculum + role/interview patterns.
- D = general knowledge.

The note must never claim that a C/D question was definitely asked.

## Source discipline
The user's exact Persistent Snowflake_MSFabric curriculum is the syllabus. Existing user training notes are preserved where useful. Current vendor facts are checked against official documentation. Public candidate reports are treated as anecdotal evidence.
