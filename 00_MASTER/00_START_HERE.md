3. Your existing training notes are the learning baseline.

## 3. How to study each topic

**Learn → explain → code → troubleshoot → connect to project → self-test.**

For every P0 concept, you should eventually be able to give a 30–60 second explanation, write a basic implementation, handle a follow-up question and explain one practical scenario.

## 4. Evidence labels

- **A:** directly reported Persistent interview context
- **B:** reported Persistent question, usually from experienced candidates
- **C:** high-probability prediction
- **D:** general interview preparation

Never treat C or D as a confirmed interview question.

## 5. Project honesty rule

- **Implemented:** you actually built or used it.
- **Studied:** it was part of training.
- **Would implement:** it is your proposed production design.

This distinction is mandatory during project cross-examination.
