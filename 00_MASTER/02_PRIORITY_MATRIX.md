## P0 standard
For each P0 subject, be able to:
1. Define it.
2. Compare related concepts.
3. Write/code common tasks.
4. Troubleshoot it.
5. Explain a realistic scenario.
6. Connect it to a project.
7. Handle follow-up questions.
