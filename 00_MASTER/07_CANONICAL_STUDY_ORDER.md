# Canonical Study Order

## Objective
Turn the handbook into an interview-performance system rather than a collection of notes.

## Phase 1 — Core interview foundation
1. SQL fundamentals and analytical SQL
2. Python fundamentals and coding
3. ETL/ELT + data engineering fundamentals
4. Data modeling + SCD + incremental processing

## Phase 2 — Distributed processing
5. Spark architecture
6. PySpark DataFrame API
7. joins, windows, JSON, partitions and shuffle
8. skew, broadcast, repartition/coalesce, caching and AQE
9. Spark troubleshooting

## Phase 3 — Snowflake specialization
10. Snowflake architecture
11. warehouses and workload management
12. micro-partitions, pruning and clustering
13. stages, file formats and COPY
14. MERGE, QUALIFY and Streams/CDC
15. semi-structured data
16. Time Travel, Fail-safe and cloning
17. performance, profiling and cost
18. security/RBAC/masking/RLS
19. UDFs, procedures and Snowpark

## Phase 4 — Transformation and orchestration
20. dbt models/materializations/tests/snapshots/incremental models
21. Azure/ADLS/ADF concepts
22. orchestration, retries, monitoring and idempotency

## Phase 5 — Microsoft Fabric specialization
23. Fabric architecture and workloads
24. OneLake
25. Lakehouse and Delta
26. Medallion architecture
27. Spark/PySpark in Fabric
28. Fabric Data Factory
29. Warehouse and SQL endpoint/T-SQL
30. star schema + Gold serving
31. Power BI and Direct Lake
32. governance/RLS/CLS/lineage
33. CI/CD and deployment

## Phase 6 — Projects
34. Disaster project: end-to-end defense
35. Cricket project: end-to-end defense
36. Explain why each technology was chosen
37. Explain what would change at 10x/100x scale
38. Explain failure, quality and security handling

## Phase 7 — Interview simulation
39. SQL coding round
40. Python/PySpark coding round
41. Snowflake/Fabric technical round
42. Architecture/scenario round
43. Project cross-examination
44. Behavioral/HR round
45. Full timed mock interview

## Study rule
A P0 topic is not complete until you can:
- explain it simply;
- answer a follow-up;
- solve a representative coding problem;
- troubleshoot a scenario;
- connect it to one of your projects.
