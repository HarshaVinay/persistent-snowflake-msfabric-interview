# SQL + Python + PySpark Master Coding Set

## SQL P0
1. Second/third highest distinct salary.
2. Top 3 employees per department.
3. Employee salary > manager salary.
4. Latest row per business key.
5. Remove duplicates while keeping latest.
6. Running total.
7. Moving average.
8. LAG/LEAD comparison.
9. Customers with no orders.
10. Conditional aggregation.
11. Duplicate groups.
12. Gaps/consecutive dates.

## Python P0
1. Frequency count using `Counter`.
2. First non-repeating character.
3. Deduplicate list while preserving order.
4. Second-largest distinct number.
5. Flatten nested list.
6. Group dictionaries by key.
7. Sort records by multiple keys.
8. Parse JSON records.
9. Exception-safe file reading.
10. Generator for large input.

## PySpark P0
1. Read CSV with explicit schema.
2. Clean nulls and invalid values.
3. Deduplicate by business key/latest timestamp.
4. Top N by group with window function.
5. Aggregate by customer/team.
6. Join fact and dimension.
7. Flatten nested JSON using `explode`.
8. Add derived columns with `when`/`otherwise`.
9. Repartition by a query key when justified.
10. Broadcast a small dimension when justified.

## Coding communication
Before coding:
- restate problem;
- clarify duplicates/ties/null semantics;
- state expected output;
- choose approach;
- code;
- test edge cases;
- give complexity at a practical level.

## Interview rule
Correctness first, then readability, then optimization. Do not optimize an unknown bottleneck.
