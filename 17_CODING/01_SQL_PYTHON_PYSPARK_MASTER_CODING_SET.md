# Master Coding Set — SQL + Python + PySpark

3. Employee > manager.
4. Top 3 per department.
5. Latest record per customer.
6. Duplicate detection/removal.
7. Customers without orders.

9. Moving average.
10. Conditional aggregation.

## Python P0
1. Count frequencies with Counter.
2. Remove duplicates preserving order.
3. Find first non-repeating character.
4. Group dictionaries by key.
5. Parse nested JSON.
6. Validate records and separate bad rows.
7. Read/write files safely.
8. Write a function with exception handling and logging.

## PySpark P0
1. Read CSV with schema.
2. Cast and clean columns.
3. Remove duplicates.
4. Handle nulls.
5. GroupBy and aggregate.
6. Join fact and dimension.
7. Top N per group with Window.

10. Write Parquet/Delta.

## Coding interview discipline
- Clarify assumptions.
- State input/output.
- Write readable code.
- Test edge cases.
- Explain complexity where meaningful.
- For PySpark, mention distributed behavior and avoid driver-side collection of large datasets.
