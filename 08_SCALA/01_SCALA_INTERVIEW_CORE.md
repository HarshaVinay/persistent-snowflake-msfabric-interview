# Scala Interview Core

## Curriculum essentials
Values vs variables, data types, expressions vs statements, conditions, loops, classes/objects, tuples, functions, pure/impure functions, higher-order functions, exceptions, List/Map/Set and functional programming.

## High-value distinctions
- `val` is immutable binding; `var` is reassignable.
- Expressions return values; statements primarily perform actions (Scala treats many constructs expression-oriented).
- Higher-order functions accept/return functions.
- Pure function: same input → same output and no observable side effects.
- List is ordered collection; Set emphasizes uniqueness; Map stores key/value pairs.

## Interview level
For this fresher DE track, prioritize conceptual fluency and basic code. Do not let obscure Scala internals displace SQL/PySpark/Snowflake.
